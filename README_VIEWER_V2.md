## ロール方式の比較・採用理由

TFXには約3か月の年限重複期間があり、実際の乗換は自動ではありません。[公式リセット説明](https://www.clickkabu365.jp/about_cfd/about_cfd24.html)

|方式|年限間の段差|長期変動の保存性|サヤ比率の解釈|指標への影響・未来情報|
|---|---|---|---|---|
|無調整接続|年限差がそのまま混入|各年限内の生価格は保存、ロールリターンに年限差が混ざる|切替時に評価基準が変化|MA/SD/Zに機械的ショック|
|差分バックアジャスト|同日旧新価格の差を過去に加算して解消|期間内の価格差を保存、騰落率は変化。長期化で負値の可能性|分子・分母の加算により比率が変形|過去値と過去の指標がロール後に変わる|
|比率バックアジャスト|同日の新/旧比を過去に掛けて解消|期間内の騰落率を保存、価格差は拡縮|最新年限基準の調整比率、生のETF比率ではない|過去値を事後変更。固定正倍率なら比のZは理論上不変でも、β差や窓をまたぐ比較への影響に注意|
|**比率の前方調整（採用）**|旧系列と新系列の同日調整値を一致させる|各採用年限の日々の騰落率を保存。絶対価格差は調整後スケール|2024年限基準の分析比率。現在の生価格比とは異なる|当日までの6価格で確定、次帳票日から適用。過去値・過去の日足指標を改訂しない|

正のETF価格でサヤ比を長期比較し、未来情報を使わないという目的から、**前方比率調整**を採用しました。絶対価格差を実損益と読む用途には適しません。生価格や生比率を確認する場合は年限別表示を使ってください。比較用の無調整・差分バック調整・比率バック調整も監査スクリプトで同じロール日に計算し、metals-viewer-audit.jsonのcomparisonに実データのロール前後騰落率を記録しています。本番UIで選択する連続系列は採用方式のみです。

### ルールと式

- 2024年限から開始。毎年10月1日以降、旧・新年限の金・銀・Pt全6終値が同日に初めてそろった日を係数確定日とする。
- 各金属 k について F_new[k] = F_old[k] × P_old[k,t] / P_new[k,t]。
- 確定日の次のTFX帳票日から3銘柄同時に新年限へ切替。表示価格 = 原本終値 × 累積係数。
- 確定日tでは旧価格を表示し、t+1以降は新価格の実際の騰落率を継承する。同日の調整価格は一致するが、市場の翌日変動を0にしない。
- 6価格のいずれかが欠ければ確定を延期。別日補間・個別銘柄だけのロールはしない。接続条件が整わないまま旧年限が終了した場合、価格を作らず接続不能理由を表示する。
- 流動性の事後ピークや将来の重複期間最終日を使って日付を決めない。ロールはViewerの固定分析ルールで、TFXの推奨乗換日や売買戦略ではない。

## MA・BB・Z仕様

選択した年限別／調整連続価格からRatio=A/BまたはSpread=A−βBを計算。週足は月曜始まり、月足は暦月で集約し、それぞれの20有効足を使います。MA=平均、SD=母標準偏差(ddof=0)、BB=MA±SDおよびMA±2SD、Z=(現在値−MA)/SD。表示期間で切り出す前に全履歴で計算します。進行中の週・月足はその時点までの価格を使うため、新しい価格の到着で最後の足は変わります。

確認済み休業日のnullは指標窓を破棄しません。未知の終値欠損は窓をリセットし、20有効足未満・SD=0では指標を算出しません。日足の休業日にはMA/BB/Zもnullを返し、休業日のZを0円から計算することはありません。系列開始19足は初期不足です。連続月足では20か月目の2025年4月から指標が表示可能です。
